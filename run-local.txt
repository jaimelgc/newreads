NewReads - Local development commands
=======================================

Local settings need no .env file and no external services (no MySQL, no
Redis) - SQLite + an in-memory cache are used automatically. Django picks
this up because DJANGO_ENV defaults to "local" (backend/newreads/settings/__init__.py).

1) Backend (Django) - run from backend/

   python -m venv .venv
   source .venv/bin/activate          # Windows: .venv\Scripts\activate
   pip install -r requirements.txt
   python manage.py migrate
   python manage.py runserver 127.0.0.1:8000

   Optional overrides (create backend/.env, all optional):
     SECRET_KEY=some-other-key
     DEBUG=True
     ALLOWED_HOSTS=127.0.0.1,localhost

2) Frontend (Vite) - run from frontend/, in a second terminal

   npm install
   npm run dev

   Uses frontend/.env.development (VITE_API_URL=/api), which is routed by
   the Vite dev proxy (frontend/vite.config.ts) to http://127.0.0.1:8000.
   Open the URL Vite prints (default http://localhost:5173).

3) Run backend tests

   cd backend && source .venv/bin/activate && python manage.py test

4) Run frontend unit tests

   cd frontend && npm run test:unit
